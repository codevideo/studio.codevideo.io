# CodeVideo Studio

Generate educational software content in minutes, not weeks.

Check it out at [studio.codevideo.io](https://studio.codevideo.io)

## Desktop app

The editor also ships as an offline desktop app (Tauri), with Kokoro speech and video renders on your computer. See [docs/desktop.md](docs/desktop.md) for running, testing, building and releasing it. A tag `vX.Y.Z` matching `package.json` builds it.
